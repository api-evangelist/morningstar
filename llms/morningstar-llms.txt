# Morningstar

> Morningstar, Inc. (Nasdaq: MORN) is a Chicago-based investment research and financial market data company. Its developer portal documents two large REST API families - Direct Web Services and Dynamic Services - on regional bases (us/emea/apac-api.morningstar.com) secured with OAuth 2.0 bearer tokens, plus Market Data Web Services, a WebSocket Streaming API, ByAllAccounts account aggregation, the Morningstar Agent API, and a hosted MCP server. Documentation and OpenAPI specs are public; credentials are sales-gated (no self-serve signup).

Generated by API Evangelist from apis.yml and the artifacts in this repository (no provider llms.txt is published; developer.morningstar.com/llms.txt returns the SPA shell).

## APIs

- [Developer portal](https://developer.morningstar.com): Direct Web Services and Dynamic Services documentation
- [Market Data Web Services](https://developer.morningstar.com/apis/market-data/overview): real-time, delayed, and end-of-day pricing, time and sales, OHLCV, corporate actions
- [Authentication API](https://developer.morningstar.com/direct-web-services/documentation/api-utilities/authentication-api/overview): POST /token/oauth issues 60-minute bearer tokens
- [Time Series API](https://developer.morningstar.com/direct-web-services/documentation/direct-web-services/time-series---sync/overview): historical prices, returns, growth, dividends (sync + async)
- [Screener APIs](https://developer.morningstar.com/direct-web-services/documentation/direct-web-services/screener---equities/overview): screen global equities and managed investments
- [Investment Details APIs](https://developer.morningstar.com/direct-web-services/documentation/direct-web-services/investment-details---equities/overview): deep security-level datapoint packages
- [Portfolio Analysis APIs](https://developer.morningstar.com/direct-web-services/documentation/direct-web-services/portfolio-x-ray/overview): X-Ray, performance, optimizer, risk score, hypotheticals
- [Financial Planning APIs](https://developer.morningstar.com/apis/financial-planning/overview): households, portfolios, retirement plans, OCR, report retrieval
- [ByAllAccounts API](https://developer.morningstar.com/apis/account-aggregation/byallaccounts/overview): held-away account aggregation for wealth platforms
- [Morningstar Agent API](https://developer.morningstar.com/direct-web-services/documentation/morningstar-ai-integrations/morningstar-agent/overview): managed financial AI agent at agents.morningstar.com
- [Morningstar MCP Server](https://developer.morningstar.com/direct-web-services/documentation/morningstar-ai-integrations/morningstar-mcp-server/overview): https://mcp.morningstar.com/mcp - 7 tools (analyst research, articles, data, fund holdings, id lookup, portfolio analysis, screener); OAuth with licensed account
